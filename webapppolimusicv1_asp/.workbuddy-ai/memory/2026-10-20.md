## Vista "Song List" de PoliMusic (ASP clásico + SQL Server)

**Objetivo**: generar la vista del listado de canciones con reproductor HTML5,
control de sesión y CRUD por roles, sobre la base `BDD_PoliMusic`.

**Stack elegido**: ASP clásico (VBScript) + ADO + SQL Server local
(`sa` / `admin04`), HTML/CSS/JS puro sin frameworks ni CDN.

**Estructura creada** (raíz del proyecto):
- `songList.asp` — vista principal, tabla server-side + reproductor por fila.
- `songActions.asp` — endpoint JSON (`create`/`update`/`delete`/`play`).
- `login.asp`, `logout.asp`, `Default.asp` — ciclo de sesión completo.
- `includes/{config,util,db,auth}.asp` — orden obligatorio de include:
  config → util → db → auth (config define las Const que usan los demás).
- `assets/css/polimusic.css` (1452 líneas), `assets/js/songlist.js`.
- `SongFilesAndImages_resources/{SongFiles,UserImages,PlaylistImages}`.
- `web.config` (ASP, MIME mp3, default document), `README.md`, `docs/screenshots/`.

**Decisiones técnicas relevantes**:
- Rutas lógicas `~/songFiles/x.mp3` se resuelven a
  `SongFilesAndImages_resources/SongFiles/x.mp3` con `ResolveResourcePath()`;
  `ResourceFileExists()` marca filas como "Sin archivo" si falta el mp3.
- Todas las consultas usan parámetros ADO (`CreateParameter`), nunca concatenación.
- El DELETE borra primero `TBL_TRACKLIST`, `TBL_PLAYER` y `TBL_PLAYLIST_SONG`
  dentro de una transacción, porque las FK impedían borrar canciones sembradas.
- `OpenConnection()` prueba 8 cadenas de conexión en cascada
  (MSOLEDBSQL, MSOLEDBSQL19, SQLNCLI11, SQLOLEDB, ODBC 18/17, SNAC11, SQL Server).
- Sesión: `USERNAME`, `USER_TYPE`, `USER_PHOTO`, `ID_USER` (escritas solo en login.asp).
- La tabla se convierte en lista de tarjetas por debajo de 780 px.

**Verificación realizada**:
- `sqlcmd` contra localhost: los 5 SELECT/INSERT/UPDATE/DELETE (con OUTPUT y
  rollback) funcionan; datos intactos.
- Analizador estático propio: bloques VBScript balanceados y sin variables
  sin declarar (Option Explicit).
- `node --check` sobre el JS y conteo de llaves del CSS.
- Render con Chrome headless (desktop, modal, móvil 390 px, login).
  Bugs corregidos: `[hidden]` no ocultaba por `display` de clase,
  `table-layout` fijo, `max-width: 22ch` en login, columna índice visible en móvil.
